# Lab Architecture

## Overview

This Active Directory home lab was built using Oracle VirtualBox to simulate a small enterprise network.

The lab consists of one Windows Server 2022 virtual machine configured as the Domain Controller and one Windows 10 virtual machine joined to the Active Directory domain.

This environment allows me to practice user management, Group Policy, delegation, authentication, and identity management in a safe and isolated lab.

---

## Lab Components

| Component | Purpose |
|-----------|----------|
| Oracle VirtualBox | Virtualization Platform |
| Windows Server 2022 | Domain Controller |
| Active Directory Domain Services (AD DS) | Identity Management |
| DNS | Name Resolution |
| Windows 10 Client | Domain-Joined Client Computer |

---

## Domain Information

| Item | Value |
|------|-------|
| Domain Name | corp.local |
| Domain Controller | AD-DC01 |
| Client Computer | WIN-CLIENT |

---

## Lab Objectives

The lab was designed to practice:

- Active Directory administration
- Organizational Units (OUs)
- User and Group Management
- Group Policy Management
- Delegation of Control
- Role-Based Access Control (RBAC)
- Principle of Least Privilege (PoLP)
- Enterprise permission management using AGDLP
