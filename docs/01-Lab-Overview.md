# Active Directory Home Lab - Lab Overview

## Project Objective

The purpose of this project is to build a hands-on Active Directory home lab to develop practical skills in identity and access management, Windows Server administration, and enterprise security concepts.

This lab simulates a real-world Active Directory environment where users, groups, Organizational Units (OUs), and Group Policies are managed securely.

Rather than focusing only on theory, this project emphasizes practical configuration, troubleshooting, and understanding how Active Directory is used in enterprise environments.

---

## Lab Environment

- Oracle VirtualBox
- Windows Server 2022 (Domain Controller)
- Windows 10 Client
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy Management

---

## Learning Objectives

Through this lab, I practiced:

- Installing and configuring Active Directory Domain Services
- Creating and managing Organizational Units (OUs)
- Managing users and security groups
- Configuring and troubleshooting Group Policy Objects (GPOs)
- Implementing Delegation of Control
- Applying the Principle of Least Privilege (PoLP)
- Understanding Role-Based Access Control (RBAC)
- Implementing enterprise permission management using the AGDLP model
